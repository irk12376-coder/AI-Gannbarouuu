# AI-Gannbarouuu

社内AI活用を推進するためのプロジェクトです。

## 概要

このリポジトリでは、社内の業務効率化・生産性向上を目的とした
AI活用の取り組み(ツール、ノウハウ、ドキュメントなど)を管理します。

## 目的

- 社内業務におけるAI活用事例の共有
- AIツール導入・運用ノウハウの蓄積
- 社内向けAI活用の推進

## 経理自動化室(マルチエージェント組織)

事務的業務をエージェントに分担させて自動化する仕組みを、このリポジトリ上に構築しています。現在は経費精算・請求書処理から着手し、段階的に対象業務を広げていく方針です。

- 組織図・メンバー一覧・使い方: [CLAUDE.md](./CLAUDE.md)
- 担当エージェント定義: `.claude/agents/`
- 判断基準(規定・閾値): `rules/`
- 処理対象ファイルの置き場: `inbox/<業務>/`
- 処理結果の出力先: `processed/<業務>/`

## 使い方

領収書や請求書を `inbox/expense/` または `inbox/invoice/` に置き、`/process-expenses` または `/process-invoices` を実行してください。詳細は [CLAUDE.md](./CLAUDE.md) を参照してください。今後、他の事務作業についても具体的な活用方法やツールの使い方をここに追記していきます。

## ライセンス

社内利用を前提としています。
