# AI-Gannbarouuu

社内AI活用を推進するためのプロジェクトです。

## 概要

このリポジトリでは、社内の業務効率化・生産性向上を目的とした
AI活用の取り組み(ツール、ノウハウ、ドキュメントなど)を管理します。

## 目的

- 定型業務・資料作成などにかかる時間をAIで削減する(**業務効率化・自動化**を主眼とする)
- 社内業務におけるAI活用事例の共有
- AIツール導入・運用ノウハウの蓄積
- 社内向けAI活用の推進

## 使い方

各ドキュメントは準備中の項目を含みます。関係者確定・ツール選定が進み次第、随時更新していきます。
まずは自分の業務でのAI活用を試し、うまくいった事例があれば [活用事例集](./docs/use-cases/) への登録にご協力ください。

## ライセンス

社内利用を前提としています。
