# AI-Gannbarouuu

社内AI活用を推進するためのプロジェクトです。

## 概要

このリポジトリでは、社内の業務効率化・生産性向上を目的とした
AI活用の取り組み(ツール、ノウハウ、ドキュメントなど)を管理します。

## 目的

- 社内業務におけるAI活用事例の共有
- AIツール導入・運用ノウハウの蓄積
- 社内向けAI活用の推進

## がんばろう株式会社(マルチエージェント組織)

事務的業務をエージェントに分担させて自動化する「会社」を、このリポジトリ上に構築しています。現在は経理部(経費精算・請求書処理)が稼働中で、今後 X運用部・インスタ運用部・YouTube運用部を段階的に開設していく方針です。

- 組織図・メンバー一覧・使い方・拡張方法: [CLAUDE.md](./CLAUDE.md)
- 組織データ(会社名・部門・役職): `company/org.json`
- 各エージェントの稼働状況(可視化用): `company/status.json`
- 担当エージェント定義: `.claude/agents/`
- 判断基準(規定・閾値): `rules/`
- 処理対象ファイルの置き場: `inbox/<業務>/`
- 処理結果の出力先: `processed/<業務>/`
- オフィス可視化Webアプリ: `webapp/`(起動方法は `webapp/README.md`)

## 使い方

領収書や請求書を `inbox/expense/` または `inbox/invoice/` に置き、`/process-expenses` または `/process-invoices` を実行してください。詳細は [CLAUDE.md](./CLAUDE.md) を参照してください。

`python3 -m http.server 8000` をリポジトリルートで起動して `http://localhost:8000/webapp/` を開くと、社長視点でオフィスの様子(稼働中のエージェントが働く姿)を見ることができます。今後、他の事務作業についても具体的な活用方法やツールの使い方をここに追記していきます。
