# webapp/ — がんばろう株式会社 オフィスビュー

`company/org.json`(組織図)と `company/status.json`(各エージェントの稼働状況)を読み込んで、Kairosoft風のオフィス画面としてビジュアル化する、ビルド不要の静的Webアプリです。

## 起動方法

`fetch` でリポジトリ直下の `company/*.json` を読みに行くため、**リポジトリのルートから**静的サーバーを起動してください(`file://` で直接開くとブラウザのCORS制限で読み込めません)。

```bash
# リポジトリのルートディレクトリで実行
python3 -m http.server 8000
```

起動したら、ブラウザで `http://localhost:8000/webapp/` を開いてください。

## 見えるもの

- 上部: 組織チェーン(社長 → 経営統括室 → 部門数)
- 各部門が「部屋」として並び、稼働中の部門(現在は経理部)ではキャラクターが部屋の中をふらふら歩き回る
- エージェントが `company/status.json` の自分のエントリを `working` に更新すると、そのキャラクターの上に吹き出しでタスク内容が表示される(4秒おきにポーリング)
- まだ実装していない部門(X運用部・インスタ運用部・YouTube運用部)は鍵付きの部屋として表示され、予定されている役職名が薄く見える

## 動作確認のしかた

1. `python3 -m http.server 8000` をリポジトリルートで起動し、`webapp/` を開く
2. 別ターミナル(または Claude Code に依頼)で `company/status.json` の `expense-report-processor` を手動で `working` に書き換えて保存する
3. 数秒待つと、経理部のキャラクターに吹き出しが表示されるのを確認できる
4. 実際に `/process-expenses` や「経費精算して」を実行すると、エージェント自身がこのファイルを更新するので、処理中は自動でキャラクターが動く
