# company/

「がんばろう株式会社」の組織データです。`webapp/` のオフィス可視化アプリと各業務エージェントが、この2つのファイルを介してやり取りします。

- `org.json` — 組織図の定義(会社名・社長・経営統括室・部門・部長・社員)。部門やエージェントを追加したらここも更新する。`status: "active"` は稼働中の部門、`"planned"` は今後開設予定の部門(webapp上は鍵付きの部屋として表示される)。
- `status.json` — 各エージェントの現在の状態(`idle` / `working`)とタスク内容。エージェントは自分の作業の開始時・終了時にここの自分のエントリを更新する(`.claude/agents/*.md` の手順を参照)。webappはこのファイルをポーリングしてキャラクターのアニメーションを切り替える。

新しい部門・エージェントを追加する際は、`org.json` にメンバーを追加し、`status.json` にも同じ `id` でエントリを追加すること。
