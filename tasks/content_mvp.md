# タスク: paystock の日次サマリを 1 行で出す MVP

Codex が Claude Code へ委託するタスクの見本。
このファイルを書き換えて委託内容を差し替える。

## 背景

`paystock alert` は「今日やること」を表示するが、
その日の判定件数をまとめて振り返る手段が無い。

## やること

1. `paystock/report/` 配下に、当日の判定結果を 1 行に要約する関数を追加する
   - 例: `2026-08-13 保有 8 銘柄 / 売り検討 1 / 様子見 7`
2. 追加した関数のユニットテストを `tests/` に書く
   - 価格データは `tests/conftest.py` の合成データを使う (ネットワーク禁止)
3. 既存の `paystock alert` の出力形式は変えない

## 変更してよい範囲

- `paystock/report/` の新規ファイルと、そこから呼ばれる最小限の変更
- `tests/` の新規テストファイル

## 変更してはいけない範囲

- `paystock/trade/` 以下 (発注まわり)
- `portfolio.yaml`、`data/`、`docs/`

## 完了条件

- `python -m pytest` が全件通る
- 追加した関数の使い方が docstring から分かる
- 仕様が曖昧な点は勝手に決めず、残課題として報告する
