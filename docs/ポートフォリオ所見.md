## 気づいた点

### 1. 上位 3 銘柄が同じ方向に動く銘柄で 80.3%

日本製鉄 (鉄鋼) + JX金属 (非鉄金属) + 三菱重工業 (重工・防衛) で **80.34%**。
業種名は違いますが、いずれも **景気敏感な素材・重工セクター** です。

- 中国の景気減速、資源価格の下落、円高 — こうした要因は
  この 3 銘柄に**同時に**効きます
- 銘柄数としては 3 つに分散していますが、リスクとしてはほぼ 1 つの賭けです

`paystock report` はこれを「セクター集中」「銘柄集中」として検出し、
実際の株価データから平均相関も計算します。相関が 0.7 を超えていれば
分散はほぼ効いていないと考えてよいです。

### 2. 三菱重工業は既定の損切り基準を超えている

−17.09% は `portfolio.yaml` の既定値 `stop_loss_pct: -12.0` を超えています。
本ツールの既定ルールでは **損切り検討** の判定になります。

ただしこれは「値動きだけを見たルール」の出力です。実際に切るかどうかは、
下げた理由 (決算なのか、防衛関連の期待剥落なのか、地合いなのか) を
確認してから決めるべきです。理由が分からないまま持ち続けるのが
いちばん危険な状態です。

なお、この銘柄への集中度 (22.49%) を考えると、
全部切るか / 半分にするか / 損切り幅を広げるか の判断は
ポートフォリオ全体の比率とセットで考える必要があります。

### 3. 現金が 0.83% しかない

押し目で買い増す余力も、損切り後に組み替える余力もほぼゼロです。
何かを売らない限り、次の一手が打てません。

集中度を下げる目的と現金を作る目的は同じ方向を向いているので、
上位 3 銘柄のどれかを一部利確・一部損切りするのが素直な整理になります。

### 4. 勝っている銘柄の比率が小さい

+44.91% と最も伸びている東京エレクトロンが 7.86% しかありません。
一方、含み損の三菱重工業は 22.49% あります。
**勝ち馬が小さく、負け馬が大きい**という、比率としては望ましくない形です。

### 5. SpaceX は機械的な判定ができない

未上場株のため市場価格が存在せず、売り時の判定対象外になります
(レポートでは「判定不可」と表示されます)。評価額の更新頻度や
売買時のスプレッドも上場株とは事情が異なるので、
テクニカル指標での管理はそもそも向きません。
現状 −22.93% ですが、これは指標では追えない部分です。

## 全体としては

トータル損益は **−274円 (−0.15%)** とほぼ横ばいです。
問題は損益そのものより **構成の偏り** で、
上位 3 銘柄が同時に下げたときに全体の 8 割が一緒に沈む形になっています。

## 次にやること

```bash
# 実際の株価で判定させる
python -m paystock report

# 保有していない銘柄から、別セクターの候補を探す
python -m paystock screen --exclude-held -n 10

# 三菱重工業について、このルールが過去どう機能したか確認する
python -m paystock backtest 7011 --days 1200
```

`screen` の結果を見るときは、スコアの高さより
**今持っていないセクターかどうか** を優先して見ると、
集中の解消につながります。
