# 社内AI活用プロジェクト 企画書

## 1. 背景

生成AIをはじめとするAI技術の急速な進化により、業務の進め方そのものを見直せる機会が広がっている。
一方で、社内では活用が個人・部署単位にとどまり、ノウハウや事例が共有されず、導入判断やセキュリティ面のルールも整備されていない。
組織として体系的にAI活用を推進する体制が必要である。

## 2. 目的

- 定型業務・資料作成・情報収集などにかかる時間をAIで削減し、業務効率化・自動化を実現する
- 部署を横断してAI活用のノウハウ・事例を蓄積し、再利用可能な形で共有する
- 安全に使えるツールとルールを整備し、誰でも安心してAIを使える状態を作る

主眼は **業務効率化・自動化** に置く。創造性向上や全社的なAIリテラシー向上は副次的な効果として扱う。

## 3. ゴール(KPI例)

| 指標 | 目標(例) | 備考 |
|---|---|---|
| AI活用による削減工数 | 対象業務の作業時間◯%削減 | 部署ごとにヒアリングして設定 |
| 登録ユースケース数 | 四半期ごとに◯件以上 | `docs/use-cases/` への登録数 |
| 利用者数 | 全社員の◯%が月1回以上利用 | アンケート or ツール利用ログ |
| ガイドライン認知度 | 説明会参加率◯% | 教育コンテンツの受講状況 |

数値は初回の関係者ヒアリング後に確定する。

## 4. 推進体制

| 役割 | 担当 | 責務 |
|---|---|---|
| 推進責任者 | (要アサイン) | プロジェクト全体の意思決定、経営層への報告 |
| 事務局 | (要アサイン) | 事例収集、ガイドライン整備、問い合わせ対応 |
| 部署別推進担当 | 各部署1名 | 部署内での事例発掘・展開、フィードバック収集 |
| セキュリティ/情報システム | (要アサイン) | 利用ツールの安全性確認、ルール策定への協力 |

## 5. 進め方(ロードマップ案)

1. **準備フェーズ**: 推進体制の確定、利用可能ツールの棚卸し、ガイドライン初版作成
2. **試行フェーズ**: 数部署でパイロット導入、業務効率化の効果測定、事例第一弾の収集
3. **展開フェーズ**: 全社説明会・教育コンテンツ公開、ガイドラインの周知徹底
4. **定着フェーズ**: 定期的な事例共有会、KPIレビュー、ガイドラインのアップデート

各フェーズの期間・開始時期は関係者確定後にここへ追記する。
