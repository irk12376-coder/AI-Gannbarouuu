# アトラス(積算ソフト)自動化の検討

## 結論

- **Claude単体ではアトラスを直接操作できない**
  外部のWindowsアプリケーションを直接クリック・入力操作する権限を持たないため。
- **Claude + RPAツールの組み合わせなら実現可能**
  Claudeが「判断」を担い、RPAツールが実際の画面操作(クリック・入力)を担う構成にすることで、
  人がアトラスを操作するのに近い自動化が実現できる。

## 構成イメージ

```
Claude (判断・指示)
   │
   ▼
RPA (実際の画面操作: クリック・入力)
   │
   ▼
アトラス (積算)
```

### 処理の流れ(例)

1. **Claudeが判断**
   例: 「舗装工 100㎡ → この歩掛と単価を使う」を決定する。
2. **RPAが操作**
   - アトラスを開く
   - 該当工種をクリック
   - 数量を入力
   - 単価を選択
3. **完成**
   ほぼ自動で積算が完成する。

## 候補となるRPAツール

| ツール | 特徴 |
|---|---|
| Power Automate (Windows) | Microsoft純正、導入しやすい |
| UiPath | 高機能、複雑な業務フローに強い |
| AutoHotkey | 軽量、単純なクリック・入力の自動化に向く |

## 難易度と効果の目安

- 難易度: 中〜高
- 効果: 大きい

例:
- 手作業: 1件あたり約3時間
- 自動化後: 1時間以下

→ 月間で数万円〜数十万円相当の工数削減が見込める。

## 注意点

- アトラスの画面レイアウトが変わると自動化が動かなくなる可能性がある
- 会社PCのセキュリティ制限により導入できない場合がある
- 誤入力・誤操作のリスクがあるため、完全放置(ノーチェック運用)は避けるべき

## 推奨する進め方(現実路線): 半自動化

いきなり全自動化を目指すのではなく、以下の半自動フローから始めることを推奨する。

1. Claudeが歩掛の候補を提示する
2. 人が候補内容を確認する
3. RPAが確認済みの内容をアトラスへ入力する

この方式が最も安定して早く効果を得られる。

## 実際に自動化フローを設計するために必要な情報

具体的なRPAフローを設計するには、以下の情報が必要になる。

- アトラスの操作画面(どこをクリックしているか)のスクリーンショットまたは手順
- 一連の作業手順(工種選択 → 数量入力 → 単価選択 など、実際の操作順序)

これらが揃い次第、具体的な自動化フロー(RPAシナリオ)を設計する。
