# 運用ガイド

毎日どう使うか、判定をどう読むかをまとめます。

## 毎日の使い方

```bash
# 朝 (寄り前) — 今日の要対応を確認する
python -m paystock report

# 大引け後 — その日の終値で判定を更新し、スマホ用の HTML を作る
python -m paystock report -f html -o report.html

# 週末 — 新しい買い候補を探す
python -m paystock screen --exclude-held -n 10
```

### 自動で毎日レポートを作る (cron)

```cron
# 平日 16:00 に HTML レポートを更新する
0 16 * * 1-5 cd /path/to/AI-Gannbarouuu && python -m paystock report -f html -o report.html
```

## 判定の読み方

| 判定 | 意味 | 想定される行動 |
| --- | --- | --- |
| **損切り検討** | 含み損が設定値を超えた | 最優先で確認する。損切りは早いほど傷が浅い |
| **売却検討** | トレンドが崩れ、売りシグナルが重なった | ポジションを減らすか全部降りるか判断する |
| **一部利確** | 過熱気味。上昇は続いているかもしれない | 1/3 程度を利確して残りを伸ばす |
| **保有継続** | 特に動く理由がない | 何もしない。これが一番多くて正常 |
| **買い増し検討** | 上昇トレンド中の押し目 | 資金と比率上限の範囲で検討する |
| **判定不可** | 価格データが無い (未上場など) | 機械では判断できない |

**「保有継続」が大半を占めるのが正常です。** 毎日何かしらのシグナルが出る
ツールは、たいてい閾値が緩すぎて手数料負けします。

## 売りスコアの内訳を必ず見る

判定だけを見て売買しないでください。レポートには
「どのルールが何点を出したか」が全部出ています。

```
■ 三菱重工業 (7011) — ▼ 売却検討
   [売  25] トレーリングストップ抵触: 高値から ATR×2.5 (4,120.5) を割り込んだ
   [売  18] デッドクロス圏: 25日線(4,050.2) が 75日線(4,310.8) を下回っている
   [買  15] RSI 売られすぎ: RSI 27.5 — 反発余地
```

この例では「売り」と出ていますが、同時に RSI は売られすぎを示しています。
つまり **トレンドは崩れているが短期的には反発しうる** 状態です。
こういうときに機械の判定だけで動くと、底で投げることになります。

## 指標の意味

| 指標 | 見ているもの |
| --- | --- |
| 25日線 / 75日線 / 200日線 | 短期・中期・長期のトレンドの向き |
| デッドクロス | 25日線が75日線を下回った状態 = 中期トレンドの転換 |
| RSI (14日) | 買われすぎ (70以上) / 売られすぎ (30以下) |
| MACD | モメンタムの向きと転換点 |
| ボリンジャーバンド | 価格が統計的にどれくらい極端な位置にあるか |
| ATR (14日) | 1日あたりの平均的な値動き幅。損切り幅の基準 |
| 52週高値からの下落率 | 高値圏か安値圏か |

## 損切りラインの考え方

推奨損切りラインは **52週高値 − ATR×2.5** です (シャンデリア・エグジット)。

- 値動きの荒い銘柄ほど損切りラインが遠くなるので、
  一時的な振れで振り落とされにくくなります
- 高値が更新されるとラインも切り上がるので、利益を守りながら伸ばせます
- ラインは下がりません。一度上がったら下げない、が肝です

ATR の倍率は `portfolio.yaml` の `atr_stop_multiple` で変えられます。
小さくすると損切りが早く・浅くなり、大きくすると遅く・深くなります。

## 株式分割に注意

PayPay 証券アプリの株数と、取得してきた株価が大きくずれている場合、
レポートに警告が出ます。

```
⚠ 設定上の単価 3,440.0 円 と現在値 688.0 円 が大きく乖離しています。
  株式分割・併合や銘柄コードの誤りを確認してください。
```

分割があると株数と単価が変わるので、`portfolio.yaml` の
`shares` / `market_value` / `pnl` をアプリの最新表示に更新してください。

## このツールが苦手なこと

正直に書いておきます。

- **決算・ニュース・業績を一切見ていません。** 好決算で急騰した銘柄と、
  不祥事で急落した銘柄を、値動きだけで同じように扱います。
- **横ばい相場に弱いです。** トレンドフォローなので、上下に振れるだけの
  相場では「買っては切られ」を繰り返します。
- **急落には間に合いません。** 日足で判定するので、
  1日で 20% 下げるような事態には対応できません。
- **未上場株 (SpaceX など) と投資信託は正しく評価できません。**
  投資信託は連動指数で代用しているだけで、基準価額や為替は見ていません。

これらは値動きだけを見るツールの構造的な限界です。
決算発表の予定やニュースは、別途自分で確認してください。
