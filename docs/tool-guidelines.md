# AIツール導入・利用ガイドライン

## 1. 目的

社員が安心してAIツールを業務活用できるよう、利用可能なツールと守るべきルールを明確にする。

## 2. 利用可能ツール一覧

| ツール名 | 用途 | 利用可否 | 申請要否 | 備考 |
|---|---|---|---|---|
| (例)Claude / ChatGPT等 | 文章作成・要約・調査 | 要確認 | 要確認 | 情報システム部門の承認後に記載 |

現時点では未確定。情報システム部門・セキュリティ担当と協議のうえ確定次第この表を更新する。

## 3. 情報の取り扱いルール

- 顧客の個人情報、機密情報、未公開の財務情報などを外部AIサービスに入力しない
- 入力してよい情報の範囲は、各ツールの利用規約・データ取扱い方針を確認したうえで判断する
- 判断に迷う場合は事務局・情報システム部門に確認してから利用する
- AIの出力結果は誤りを含む可能性があるため、重要な判断や対外的な資料に使う前に必ず人が内容を確認する

## 4. 新しいツールの申請フロー

1. 利用したいツールと用途を事務局に申し込む
2. 情報システム部門がセキュリティ・データ取扱いの観点で確認する
3. 承認された場合、本ドキュメントの「利用可能ツール一覧」に追加する
4. 却下された場合は理由を申請者にフィードバックする

## 5. 違反時の対応

ルール違反や情報漏えいの懸念が生じた場合は、速やかに事務局および情報システム部門に報告する。
報告を理由に不利益な扱いは行わない。
