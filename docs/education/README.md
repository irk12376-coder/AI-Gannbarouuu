# 社内展開・教育コンテンツ

社員がAIを日常業務で使いこなせるようになるための展開施策・教材をまとめるディレクトリです。

## コンテンツ

| コンテンツ | 対象 | 状態 |
|---|---|---|
| キックオフ説明会資料 | 全社員 | 未作成 |
| 基本の使い方ガイド(プロンプトの書き方など) | 全社員 | 未作成 |
| 部署別ハンズオン資料 | 各部署 | 未作成 |
| FAQ | 全社員 | [`FAQ.md`](./FAQ.md) 参照 |

## 展開の進め方(案)

1. キックオフ説明会でプロジェクトの目的・ガイドラインを周知する
2. 基本の使い方ガイドを配布し、まず一人で試してもらう
3. 部署別推進担当が中心となり、部署の業務に即したハンズオンを実施する
4. 定期的な事例共有会を開催し、`docs/use-cases/` への登録を促す
