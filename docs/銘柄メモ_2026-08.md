| 項目 | 値 |
| --- | --- |
| 直近株価 | 4,044円 (8/7, +1.15%) |
| 決算前 (8/3) | 3,799円 |
| 取得単価 | 約4,774円 |

**8/4 の 1Q 決算**: 売上 +15.5% (1兆1,942億円)、営業利益 **+65.1%** (1,596億円)、
純利益 **+97.4%** (1,347億円)。

**読み方**: ここが判断の分かれ目です。

含み損 −17.09% は本ツールの既定の損切り基準 (−12%) を超えており、
**ルール上は「損切り検討」が出ます**。しかし:

- 8/4の決算は大幅増益
- 決算後に 3,799円 → 4,044円 と **+6.4%** 上昇している
- つまり**下げ止まって反転しかけている局面**

機械的な損切りルールは「下がり続けるものを持ち続けない」ためのものです。
反転しかけている局面での発動は、ルールが最も裏目に出やすいケースです。

取得単価4,774円まで戻るには現値から+20%必要で、簡単ではありません。
ただし「今すぐ全部投げる」か「戻りを待つ」かは、
−17%という数字だけでなく **決算が良かったという事実** を含めて判断する場面です。
