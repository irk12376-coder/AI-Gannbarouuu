# AI活用事例集

社内でのAI活用事例を蓄積し、他部署でも再利用できるようにするためのディレクトリです。

## 登録方法

1. [`TEMPLATE.md`](./TEMPLATE.md) をコピーする
2. ファイル名を `部署名-内容が分かる短い名前.md` の形式にする(例: `sales-見積書ドラフト作成.md`)
3. テンプレートに沿って記入し、このディレクトリに追加する
4. プルリクエストを作成し、事務局のレビューを受ける
